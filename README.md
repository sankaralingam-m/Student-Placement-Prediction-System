# Student-Placement-Prediction-System
# AI Placement Intelligence

A machine learning-powered web application that predicts student placement outcomes based on academic performance, skills, projects, internships, certifications, and other factors.

## Features

* Student placement prediction
* Logistic Regression model
* Confidence score
* AI recommendations
* Modern dashboard UI
* Flask web application

## Tech Stack

* Python
* Flask
* Scikit-learn
* Pandas
* NumPy
* HTML
* CSS
* JavaScript

## Machine Learning

Model Used:

* Logistic Regression

Dataset Size:

* 45,000 student records

Accuracy:

* 86.44%

## Project Structure

app.py → Flask backend

preprocess.py → Model training

templates/ → HTML pages

static/ → CSS and JavaScript

model/ → Trained ML model

## How to Run

1. Clone repository
2. Install dependencies

pip install -r requirements.txt

3. Run application

python app.py

4. Open browser

http://127.0.0.1:5000
